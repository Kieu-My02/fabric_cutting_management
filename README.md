# Fabric Cutting Management

Module Odoo 19 quản lý quy trình vải cho doanh nghiệp may mặc.

## Chức năng

- Quản lý cây vải
- Kiểm tra QC
- Cấp phát vải
- Quản lý trả vải
- Báo cáo tồn kho
- Báo cáo thiếu vải
- Dashboard Power BI
- Thanh toán VNPay

## Yêu cầu

- Odoo 19
- Python 3.12+
- PostgreSQL

## Cài đặt

Đặt module vào thư mục addons và cập nhật Apps.
